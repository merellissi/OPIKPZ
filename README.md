# Управління життєвим циклом програмного продукту та інструменти програмної інженерії

## Опис проєкту

Цей репозиторій призначений для зберігання технічної документації та результатів практичних робіт, пов'язаних з управлінням життєвим циклом програмного продукту.

## Мета

Навчитися планувати розробку програмного забезпечення, обирати модель життєвого циклу, визначати етапи розробки, планувати завдання та використовувати інструменти програмної інженерії.

## Структура репозиторію

- `docs/` — документація проєкту та звіти з практичних робіт.
- `docs/board/` — скриншоти дошки задач і плани спринтів.
- `src/` — каталог для майбутнього вихідного коду.
- `tests/` — каталог для майбутніх тестів.
- `.gitignore` — перелік файлів, які Git не повинен відстежувати.
- `.gitattributes` — правила обробки текстових і бінарних файлів.
