# NFC Access & Time Tracker

Корпоративна система обліку робочого часу співробітників за технологією NFC.

## Опис проєкту

Система призначена для автоматичного обліку робочого часу співробітників підприємства. Співробітник підносить NFC-картку до смартфона, і система фіксує подію проходу (чек-ін / чек-аут). Менеджер переглядає журнал відвідувань і формує звіти через веб-панель.

## Тип системи

Mobile (Android-застосунок) + Web/API (панель адміністратора та REST API).

## Замовник і команда

- Замовник: внутрішній IT-департамент / Відділ кадрів підприємства.
- Команда: 4 особи (Backend-розробник, Mobile/Frontend-розробник, QA-інженер, DevOps/Lead).
- Методологія: Scrum (4 спринти по 2 тижні).
