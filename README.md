# NFC Access & Time Tracker

Корпоративна система обліку робочого часу працівників за допомогою NFC: працівник прикладає NFC-картку до смартфона — система фіксує прихід або вихід, а менеджер переглядає журнал відвідуваності та формує звіти у веб-панелі. Проєкт призначений для IT- та HR-відділу компанії.

> **Поточний стан:** репозиторій містить технічну документацію та результати практичних робіт з дисципліни «Організація процесів інженерії програмного забезпечення». Програмний код (`src/`) і тести (`tests/`) будуть додані на наступних етапах.

## Можливості

- Реєстрація приходу / виходу працівника одним дотиком NFC-картки до смартфона
- Журнал відвідуваності з датою, часом і працівником
- Веб-панель для менеджера: перегляд відміток, фільтр за працівником і періодом
- Формування звітів про відпрацьований час
- REST API для інтеграції з іншими системами компанії

## Технології

| Частина | Технологія |
|---|---|
| Мобільний застосунок | Android (NFC) |
| Сервер / API | C#, ASP.NET Core, REST API |
| База даних | PostgreSQL (міграції — Entity Framework Core) |
| CI/CD | GitHub Actions, Docker |

## Встановлення / запуск

Отримати робочу копію репозиторію:

```bash
git clone https://github.com/merellissi/OPIKPZ.git
cd OPIKPZ
```

Документація знаходиться в теці `docs/` — її можна переглядати прямо на GitHub або в будь-якому редакторі з підтримкою Markdown.

Запуск серверної частини (після появи коду в `src/`):

```bash
docker compose up -d   # PostgreSQL
dotnet run --project src/Server
```

## Приклад використання

1. Працівник відкриває мобільний застосунок і прикладає NFC-картку до смартфона.
2. Застосунок надсилає запит до API:
   ```http
   POST /api/v1/events/scan
   { "cardId": "04A1B2C3", "type": "check-in" }
   ```
3. Менеджер відкриває веб-панель і бачить запис: *Іваненко О. — прихід — 09:02*.
